BepInExの警告・エラーをSea Powerのゲーム画面に通知するMODです。

- 起動中のログはメニュー表示後にまとめて通知し、その後もWarning / Error / Fatalを監視します。
- F8で履歴・詳細を表示し、ログをコピーできます。
- 個別の通知抑止・解除、一括解除に対応し、設定を再起動後も保持します。
- Warningは黄橙、Error／Fatalは赤で表示し、履歴とポップアップで色を統一しています。

導入にはBepInExとAnchor Chainが必要です。配布ZIPを展開し、`BepInExLogAlerts`フォルダを`Sea Power_Data/StreamingAssets`へコピーして、MODマネージャーで有効にしてください。

`SHA256SUMS.txt`に配布ZIPのハッシュを記載しています。既存の30項目の動作検証と、ゲーム付属Monoでの5項目の統合検証が成功しています。

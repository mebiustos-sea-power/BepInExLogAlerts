Displays BepInEx warnings and errors directly in Sea Power.

- Startup messages are shown together after the main menu appears; Warning / Error / Fatal messages continue to be monitored afterwards.
- Press F8 to view history and message details, and copy logs.
- Mute or unmute individual messages, or reset all mute settings. Settings persist across game restarts.
- Warning messages use yellow-orange stripes and Error/Fatal messages use red, consistently across history and popups.

Requires BepInEx and Anchor Chain. Extract the download ZIP, copy the `BepInExLogAlerts` folder into `Sea Power_Data/StreamingAssets`, enable the mod in the mod manager, and restart the game.

`SHA256SUMS.txt` contains the SHA256 hash of the download ZIP. The existing 30 behavioral checks and 5 integration checks using the game's bundled Mono runtime passed.
